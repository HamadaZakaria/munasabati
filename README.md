# مناسبتي

فيديو تهنئة باسمك لأي مناسبة، جاهز في ثوانٍ وبالعربي: رمضان، عيد الفطر والأضحى، رأس السنة الهجرية، المولد النبوي، الإسراء والمعراج، عيد الميلاد، عيد الغطاس، عيد القيامة، شم النسيم، عيد الأم، رأس السنة، زفاف، وعيد ميلاد.

🌐 الموقع: https://hamadazakaria.github.io/munasabati/

المعاينة بتترسم حي على الصفحة (Canvas) — اختار المناسبة، اكتب الاسم، وشوف التهنئة قدامك. مواعيد المناسبات الهجرية متوقعة فلكيًا وتتأكد برؤية الهلال.

من نفس الصانع: [عداد رمضان ١٤٤٨ وصانع فيديو التهاني](https://ramadankarym.github.io/)
